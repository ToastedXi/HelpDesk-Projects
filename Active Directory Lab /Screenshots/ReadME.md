# Screenshots

This folder contains screenshots documenting the setup, configuration, troubleshooting, and administration of the Active Directory home lab environment.

The screenshots included demonstrate:
- VirtualBox network configuration
- Windows Server 2022 setup
- Active Directory Domain Services installation
- Domain Controller promotion
- DNS configuration and troubleshooting
- Windows 11 domain join
- Organizational Units (OUs)
- User and group creation
- PowerShell administration
- Active Directory enumeration commands
- Network troubleshooting steps

These screenshots were captured throughout the project to document the learning process and provide visual evidence of the completed lab environment.
